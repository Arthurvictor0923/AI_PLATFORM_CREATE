# 北大荒智慧农业协同创新平台 · 门户原型

本包包含已修订的20个 HTML 页面、9张原始素材图和参考说明，可作为完整静态网站上传。

## 如何使用

1. 解压压缩包；解压后应直接看到 `index.html`、其他 HTML 和 `assets` 文件夹。
2. 本地查看：双击 `index.html`。保持文件之间的相对位置，图片即可显示。
3. 在线查看：将解压后的全部内容提交到 Git 仓库，将含 `index.html` 的这一层设置为静态网站发布目录。
4. 通过静态网站网址访问；仓库文件浏览页不是原型网站网址。

不要只上传 HTML，也不要仅把 ZIP 文件上传到仓库。

## 开发说明与交互演示指引

每页右下角有两个悬浮入口，供开发、测试、产品核对字段与交互：

- **📋 字段说明**：按业务功能分 Tab，逐字段给出类型、长度/取值、是否必填、说明与校验规则。
- **🧪 交互演示指引**：按业务功能分 Tab，逐条给出交互场景、触发方式、预期效果，并说明状态流转与按钮可用性口径。

两个悬浮入口与抽屉均可拖动，抽屉支持 <kbd>Esc</kbd> 或点击遮罩关闭。

字段长度口径来源：① 本原型真实输入框的 `maxlength`（如需求标题 40 字、需求概述 200 字）；② 《模型上架元数据与接入配置_字段清单_v1》；③ 《需求中心-定版功能清单与功能点》；④ `assets/meeting/meeting-core.js` 内的元数据 schema 与提交校验。凡本项目文档未定义、按尺度与行业惯例给出的参考值，均在抽屉底部注明为「建议」，最终以后端确认或接口文档为准。

### 本轮账号、团队与权限调整

- 个人中心新增“成员账号”，负责人可以在尚无团队时创建关联成员；姓名、登录账号、初始密码为必填。普通成员绑定一个负责人，可加入其名下多个团队。
- “我的团队”新增创建团队。团队详情“添加成员”分为选择本人已有成员账号、邀请本机构已有独立负责人。邀请支持接受、拒绝和取消。
- 受邀负责人在该团队按普通成员参与，仍可管理自己创建的团队。移出一个团队保留账号及其他团队关系。
- 成员可试用模型、申请模型在线使用、发布需求；不能申请数据、模型开发、科研空间或算力，不能创建账号 / 团队或正式提交成果。
- 后台复用机构、账号、团队和成员关系；本包只调整门户，后台共用要求见同步交付的需求说明和开发计划。

## 团队课题与需求关联补充

- 创建团队可分别选填关联课题、关联需求；创建后在团队详情的关联区域维护或解除。
- 课题沿用一个开发团队字段，一个团队可关联多项课题。可选课题限当前负责人有权关联的范围，不能覆盖其他团队已有绑定。
- 需求选择当前可见的已发布记录；关联不改变发布人、发布状态或合作状态。
- 个人中心新增“我的课题”，按已加入团队汇总并展示课题内容。普通成员、受邀负责人可查看，无课题编辑和状态维护权限。
- 张研究员负责两个团队、参与一个团队；李晓可查看两个团队关联的课题；赵晨无团队，列表为空；刘老师可在创建团队时关联已有示例课题。
- 团队关系、课题内容和需求引用使用同一份本地记录；不通过名称匹配，也不另建课题或需求副本。正式数据与权限由既有系统接口提供。

## 原型范围

保留上一版的占位修订及交互，不重新设计业务页面。咨询、申请、运行等均为演示。
跨页面记录联动需在同一站点环境下预览；直接双击本地 HTML 时，浏览器可能隔离不同文件的本地存储。
地图查询页沿用原型中的在线地图服务，实际地图加载取决于服务可用性与部署域名配置。本包的9张素材图不依赖第三方图床。

素材包中的原始设计说明可能包含历史路径与旧版本建议；本次发布目录和图片引用以本 README 与 HTML 为准。
