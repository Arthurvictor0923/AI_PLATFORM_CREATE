🧪 交互演示指引 — 知识库原型 ✕
📋 一、文档管理
交互场景触发方式预期效果
选择文档点击左侧文档列表中的文档名称右侧编辑器加载文档内容，信息栏同步更新
折叠分类点击左侧分类标题行分类下的文档列表折叠/展开，箭头旋转
搜索文档在左侧搜索框输入关键词，如「模型」或「病害」文档列表实时过滤，匹配的文档高亮
新建文档 弹窗点击左下角「＋ 新建文档」按钮弹出简易 Prompt 对话框，输入标题后创建草稿文档并自动选中
状态指示观察文档名称右侧圆点绿点 = 已发布，橙点 = 草稿
🖊️ 二、富文本编辑
交互场景触发方式预期效果
标题切换选中文字 → 点击工具栏「正文」下拉 → 选择标题级别文字切换为对应标题格式
加粗/斜体 Ctrl+B/I选中文字 → 点击 B / I 按钮文字应用对应格式
有序/无序列表选中多行文字 → 点击列表按钮文字转为列表项
插入链接选中文字 → 点击 🔗 → 输入 URL文字转为超链接
插入表格点击 ⊞ 按钮Prompt 对话框输入行列数 → 插入 HTML 表格
代码块选中文字 → 格式下拉选「代码块」文字转为 pre code 格式
撤销/重做 Ctrl+Z/Y点击 ↩ / ↪ 按钮或使用键盘快捷键撤销或重做上一步编辑操作
字数统计在编辑器中输入文字底部信息栏右侧实时更新字数统计
💾 三、保存与发布
交互场景触发方式预期效果
保存草稿编辑内容 → 点击底部「💾 保存草稿」Toast 提示「草稿已保存」，文档状态保持草稿
发布文档 Toast点击「📤 发布文档」状态变为已发布，绿点更新，Toast 提示发布成功
页面说明点击浮动「🧪 交互演示指引」按钮展开本指引面板
