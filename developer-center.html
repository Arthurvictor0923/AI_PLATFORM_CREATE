路径 ① · 5 分钟调通作物病害识别

1
获取 API 密钥
前往个人凭证 → API 密钥，创建 sk-xxxx
2
选择能力
在API 中心「能力目录」选「作物病害识别」
3
发送请求
用调试台或下方代码发起调用
# Python 调用示例（需先安装 SDK）
import bdhaiplatform

client = bdhaiplatform.Client(api_key="sk-your-key")

resp = client.models.predict(
    model="crop-disease-v3",
    inputs={"image": "https://img/leaf.jpg"}
)
print(resp.json())
# → {"label": "稻瘟病", "score": 0.92}

SDK & 工具

提供多语言客户端与命令行工具。
🐍
Python SDK

官方 Python 客户端，支持模型推理、知识库问答。

pip install bdhaiplatform
☕
Java SDK

Maven 依赖，适用于后端服务集成。

<dependency>
  <groupId>ai.bdhaiplatform</groupId>
  <artifactId>bdhaiplatform-java</artifactId>
</dependency>
🐹
Go SDK

Go 模块，轻量、无第三方重依赖。

go get ai.bdhaiplatform/sdk-go
⌨️
CLI 命令行

脚本化调用、CI/CD 流水线集成。

brew install bdhaiplatform-cli
